A QUICK START

三步，开始你的下一首歌

  1. 导入音乐

    选择音乐文件或带有音轨的视频。清晰的吉他伴奏比复杂的乐队混音更容易识别。

  2. 定制编配

    选择分解和弦或扫弦，设置变调夹。生成后可参考推荐品位，让左手更轻松。

  3. 试听、校对、练习

    点击谱面上的和弦即可修改。橙色圆点表示建议复核。用原音对照节拍，再打印或导出到打谱软件。

当前版本生成弹唱伴奏，支持大、小三和弦。指弹独奏（旋律 + 低音）尚未实现。分解和弦是伴奏织体，不等同于指弹独奏。

文件仅在运行此应用的机器上分析，不发送至第三方服务。作品保存在本机，点击“删除此作品”可移除该作品音轨与分析数据。
